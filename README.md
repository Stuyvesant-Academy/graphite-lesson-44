# Graphite — Saxon Algebra 2, Lesson 44

Paper-first coach for **Solving Right Triangles**. Write each move on paper, type a piece of it, unlock the next step.

Built in Grok Build. ADHD-oriented: one step at a time, cream page, Atkinson Hyperlegible, hints on/off.

## What’s in here

- `src/data/lesson.ts` — the lesson (SOH CAH TOA, inverses, two worked triangles, two solos)
- `src/components/` — player, write-gates, triangle, calculator
- `src/lib/check.ts` — degree-mode expression calculator (`20 × cos 32`)
- `src/lib/hints.ts` — answer-hint toggle

## Run

This repo is a snapshot of a Grok Build app (TanStack Start). Easiest path: open a new Grok Build on the account you want, point it at this repo, and say “run this.”

Locally, after `npm install`:

```
npm run dev
```

The Grok preview expects port 8080.
